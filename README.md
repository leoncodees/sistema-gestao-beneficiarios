# sistema-gestao-beneficiarios
Sistema de Gestão e Acompanhamento de Beneficiários e Atividades Sociais da Associação Beneficente Criança Cidadã de Santo André.
## Revisão técnica do MVP

O MVP foi desenvolvido para apoiar o cadastro e acompanhamento
de beneficiários e atividades sociais da Associação Beneficente
Criança Cidadã de Santo André.

### Funcionalidades iniciais

- Cadastro de beneficiários
- Listagem de beneficiários
- Controle de frequência
- Cadastro de atividades
- Consulta de histórico
- Geração de relatórios

### Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub Pages
